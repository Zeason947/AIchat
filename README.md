# ACM

 ACM，全称Ai-Chat-Miuix
 一个基于 Jetpack Compose 与 Miuix KMP 的 Android AI 聊天客户端。

---

## 功能特色

- **风格设计**：由 `miuix-kmp` 组件库构建，旨在学习小米 MIUI / Xiaomi HyperOS 的设计语言，组件库来自来自`https://github.com/compose-miuix-ui/miuix`
- **联网搜索与访问网页**：内置 Tool Calling机制，支持实时联网搜索 和指定网页内容访问 ，轻松获取最新资讯。
- **深度思考模式**：支持各大模型的深度思考/推理过程展示（如 DeepSeek `reasoning_content`、OpenAI `reasoning_effort` 等），提供可折叠的沉浸式思考链 UI。
- **上下文与提示词管理**：
  - 自定义系统提示词（System Prompt）。
  - 可视化与 JSON 源上下文双模式管理，支持查看、校验及修改历史对话。
  - 历史消息轮数自由控制。
**兼容 OpenAI 标准 API**：支持任意兼容 OpenAI 格式的 API 服务商（如 DeepSeek、OpenAI 等）。
